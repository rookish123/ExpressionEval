# 表达式求值

数据结构课程实验工程：把栈的三个练习整合进一个 Visual Studio C 语言项目，运行时用控制台菜单选择功能。

## 功能

| 菜单 | 功能 | 说明 |
| --- | --- | --- |
| 1 | 表达式求值 | 输入中缀表达式，支持 `+ - * /`、小括号、小数和开头的负号；先转后缀，再用数字栈求值 |
| 2 | 十进制转 M 进制 | 输入「十进制数 目标进制」，进制范围 2~16，10 以上用大写 A~F；用链栈实现 |
| 3 | 括号匹配 | 手动输入一串括号，`()` `[]` `{}` 可混用；能报出第一个出错括号的位置和原因；输入 q 返回菜单 |

## 目录结构

```
src/
  main.c        菜单与输入循环
  caculate.c    顺序栈（数字栈、字符栈）、中缀转后缀、后缀表达式求值
  brackets.c    括号匹配（独立的栈结构，记录每个括号的序号）
  linkstack.c   链栈基本操作、十进制转 M 进制
  stack.h       结构体定义与函数声明

备份/          整理前的 .bak 源文件备份，不参与编译
表达式求值.sln / 表达式求值.vcxproj    Visual Studio 工程（源码路径指向 src）
README.md      本说明
.gitignore     忽略 .vs、Debug、x64、*.user、*.bak

.vs/、Debug/、x64/ 是 VS 打开或编译后自动生成的，已在 .gitignore 中忽略，可随时删除。
```

## 编译运行

1. 用 Visual Studio 2019/2022 打开 `表达式求值.sln`；
2. 选择 `x64` + `Debug`，生成解决方案；
3. Ctrl+F5 运行，按菜单输入 1/2/3，输入 0 退出。

## 输入示例

- 选择 1，输入 `(1+2)*3-4/2`，结果为 `7`
- 选择 2，输入 `255 16`，结果为 `FF`
- 选择 3，输入 `([{}])`，提示「括号配对正确，共 3 对括号」；输入 `([)]`，提示类型不匹配

## 说明

源码使用 GBK 编码（Visual Studio 中文环境的默认编码），本地编译运行正常；在 GitHub 网页上查看时中文提示可能显示为乱码，以本地运行结果为准。
